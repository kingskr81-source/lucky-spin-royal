# LUCKY SPIN ROYAL — V3.3

A standalone browser prototype for an original virtual-coin arcade. The featured playable machine is **Aztec Gold Riches**; the other seven game cards remain previews.

## V3.3 changes
- Added a compact live XP progress bar beside the level indicator in the sticky header.
- XP is awarded for every paid spin and every free spin.
- Winning spins award additional XP; three-win streaks, every fifth win, and every tenth spin grant milestone XP bonuses.
- Replaced the basic Aztec symbol set with custom inline SVG artwork inspired by Aztec sunstone, jaguar, eagle, obsidian mask, temple idol, gold medallion, feathered serpent Wild, and sun-calendar Scatter motifs.
- Preserved the existing local-save key so the same browser profile can continue its current virtual progress.

## Run locally
Open `index.html` in a current version of Chrome or Edge. No build step or external libraries are required.

## Publish with GitHub Pages
1. Back up your current repository before replacing anything.
2. Upload the contents of this folder to the repository root (keep `index.html` at the root).
3. Commit to `main`.
4. GitHub Pages should continue using `main` and `/(root)`.

## Important
- This is a virtual-coin entertainment prototype. Coins have no cash value; there are no deposits or cash-outs.
- Player progress is saved locally in the browser. GitHub Pages does not provide cross-device accounts or cloud synchronisation.
- The other seven machines are previews, not playable games yet.
- Outcomes and rewards are prototype values and have not been independently audited.
